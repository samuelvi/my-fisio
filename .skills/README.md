# Deprecated PCMS skill source

The maintained library is the independent sibling repository
[TinaFisioBackendSkills](../../TinaFisioBackendSkills/README.md).

Its curated `pcms-*` skills replace these historical definitions. Complete
original directories, assets and license notices are preserved there with hashes
in `sources.lock.json`; duplicates have explicit provenance aliases.

Do not load or update the old bodies as current PCMS guidance. They are retained
for compatibility/history during migration. Use the external OpenCode adapter
and the backend [agent entry point](../AGENTS.md).
